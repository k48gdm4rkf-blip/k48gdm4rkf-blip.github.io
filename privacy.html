بيانات اللعبة

النسخة الحالية لعبة HTML تعمل داخل المتصفح. قد تُخزّن إعدادات اللعبة وتقدمها محلياً على جهازك بحسب الميزات التي تستخدمها. عند اختيار تصدير الحفظ، يُنشأ ملف يمكنك الاحتفاظ به أو مشاركته باختيارك.

استضافة الموقع

يُستضاف موقع Dicefront حالياً عبر GitHub Pages، وهي خدمة تابعة لـ GitHub. عند زيارة الموقع، قد تعالج GitHub معلومات تقنية مثل عنوان IP وبيانات الطلب وسجلات الوصول لتقديم الخدمة وتأمينها. للمزيد، راجع بيان خصوصية GitHub.

الإعلانات وملفات تعريف الارتباط

مساحات الإعلانات الحالية مجرد أماكن تجريبية، ولا تعني تفعيل Google AdSense. عند تفعيل AdSense لاحقاً، يجب تحديث هذه السياسة قبل تشغيل الإعلانات لتوضيح استخدام Google وشركائها لملفات تعريف الارتباط والبيانات وإتاحة الخيارات القانونية المطلوبة.

يمكن قراءة معلومات Google حول تقنيات الإعلانات. بما أن الموقع متاح عالمياً، سنجهّز قبل تفعيل إعلانات Google آلية موافقة مناسبة للزوار في المنطقة الاقتصادية الأوروبية والمملكة المتحدة وسويسرا، باستخدام منصة إدارة موافقة معتمدة من Google عندما تنطبق متطلباتها. لا تُعرض إعلانات AdSense الفعلية في النسخة الحالية.

التواصل

للاستفسارات المتعلقة بالخصوصية أو طلبات المستخدمين، تواصل معنا عبر Dicefront.support@gmail.com أو زر صفحة التواصل.

التحديثات

قد تتغير هذه السياسة عند إضافة الإعلانات الفعلية أو أدوات القياس أو تغيير خدمات الموقع. سنحدّثها لتعكس الخدمات المستخدمة فعلياً قبل تفعيل أي خدمة جديدة تتطلب إفصاحاً إضافياً.
